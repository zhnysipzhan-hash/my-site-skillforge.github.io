# SkillForge – Online Learning Platform

Қазақстан тіліндегі заманауи онлайн білім беру платформасының веб-сайты.

## 📁 Жоба құрылымы

```
SkillForge/
├── index.html          # Басты бет
├── courses.html        # Курстар каталогы
├── about.html          # Біз туралы
├── contact.html        # Байланыс
├── css/
│   └── style.css       # Негізгі стильдер
├── js/
│   └── script.js       # JavaScript функционал
├── images/
│   ├── hero.jpg
│   ├── course1.jpg
│   ├── course2.jpg
│   └── team.jpg
├── audio/
│   └── podcast.mp3
└── README.md
```

## 🚀 Іске қосу

1. `index.html` файлын браузерде ашыңыз
2. Немесе локальды сервер іске қосыңыз:

```bash
# Python арқылы
python -m http.server 8080

# Node.js арқылы (npx)
npx serve .
```

Содан кейін браузерде: `http://localhost:8080`

## 🌐 GitHub Pages-ке жариялау

1. GitHub-та жаңа repository жасаңыз
2. Барлық файлдарды push жасаңыз
3. Settings → Pages → Source: `main` branch, folder: `/ (root)`
4. Сайт `{username}.github.io/SkillForge/` адресінде ашылады
